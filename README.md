# 💾 Nerzon Parody Portfolio Design Service

A viral, satirical early-2000s / Windows XP web design service landing page for **John Nerzon Polintan**, satirizing modern \$10,000 corporate agency extortion and over-engineered developer portfolios.

Inspired by early-2000s web nostalgia, classic Windows XP Luna desktop environments, Geocities flair, and viral web experiments like `pikzels.kumar-coding.dev`.

---

## 🌟 Highlights & Nostalgic Features

- **Windows XP Luna Chrome & Beveled UI:** Authentic window titlebars, CRT monitor preview frames, blinking marquees, and retro web badges.
- **Windows XP System Properties & Device Manager:**
  - **General:** GenuineIntel Pentium II 350MHz specs, 64MB RAM, Registered to John Nerzon Polintan, and Yahoo! Messenger ID (`Waxedge27`).
  - **Yahoo! BUZZ! Easter Egg:** Clicking the Yahoo badge shakes the entire screen violently and copies `Waxedge27`.
  - **Device Manager:** Expandable hardware/software driver tree with working status checks.
  - **Tech Stack:** 15-software nostalgia grid (Dreamweaver, Notepad, Nero Burning ROM, LimeWire, MS-DOS, Lotus 1-2-3, Macromedia Flash, Movie Maker, Winamp, Netscape 4.7, MS Paint/WordArt, mIRC, Encarta 95, ICQ 99b).
- **Windows Media Player 9 Hero Showcase:** Plays a vintage cartoon commercial loop (`nerzon-commercial.mp4`) with CRT scanlines, dial-up timeline scrubber, and auto audio-ducking.
- **Flying Ambient Retro Objects:**
  - LimeWire slice (Trojan download prank toast)
  - Nero Burning ROM disc (Buffer Underrun coaster toast)
  - 3.5" Floppy Disk (Disk 14 of 42 installation prompt)
  - DVD bounce badge, Lost Uncentered `<div>`, and 99.4% OFF hot deal starburst.
- **Interactive AI Portfolio Generator:** Satirical builder with options ("Center a div (+$500)", "Spinning 3D skull"), fake loading sequence, red-arrow CAPTCHA, and live retro CRT preview.
- **"Call Nerzon Live" Hotline:** DTMF tone dialing, typing SFX, and simulated tech support banter.
- **"Chibi Nerzon" Mascot:** Floating assistant dispensing unhelpful CSS advice.
- **"Contact Nerzon.exe":** Working Windows XP dialog funneling inquiries to `erzon22@gmail.com`, GitHub [`loloerzon-sudo`](https://github.com/loloerzon-sudo), and [nerzon.online](https://nerzon.online).
- **Retro Audio Synthesizer:** Pure Web Audio API synthesizers for dings, bongs, rings, boings, pops, and background music.
- **Pixel Cursors & DHTML Trail:** Windows 98/XP cursor with classic 2000s star/sparkle trailing mouse movement.

---

## 🛠️ Tech Stack

- **Runtime / Bundler:** Vite 6
- **Architecture:** Vanilla JavaScript (ES modules) + Modular CSS (Luna / WinXP design system)
- **Audio:** Web Audio API (Synthesizers & custom SFX)
- **Deployment:** GitHub Pages (automated via GitHub Actions) with relative static paths (`base: './'`)

---

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server (runs on port 3049)
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
